安装 ​

  • nrm —— npm resource manager (npm 源管理器)
js
// 全局安装
npm install nrm -g
1
2

nrm 的指令 ​

js
nrm - V // 看nrm 安装的版本
nrm ls  // 查看可选源 星号代表当前使用源
nrm current  // 查看当前源
nrm use <registry>   // 切换源
nrm add <registry> <url>  // 添加源
nrm del <registry>  // 删除源
nrm test <registry>  // 测试源速度
