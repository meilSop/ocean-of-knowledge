具体流程 ​

  • 首先，你需要安装所需的依赖：
npm install --save-dev @babel/core @babel/preset-env rollup-plugin-babel
1
  • 其中:

@babel/core 是 Babel 编译器本身，你需要它来转换代码

@babel/preset-env 是一组可自动应用 ES6 新特性的插件

rollup-plugin-babel 让 Rollup 知道如何使用 Babel

  • 然后，你需要在你的项目根目录创建一个.babelrc 文件，内容如下：
JS
{
  "presets": [["@babel/env", {
    "modules": false
  }]]
}
1
2
3
4
5

这个文件告诉 Babel 使用 env 预设，该预设包含了需要转换 ES6 代码到 ES5 的所有 Babel 插件，并且关闭了模块转换，因为 Rollup 将会处理模块。

  • 最后，在你的 rollup.config.js 文件中引入和使用 rollup-plugin-babel ：
JS
import babel from 'rollup-plugin-babel';

export default {
  entry: 'src/index.js',
  format: 'cjs',
  plugins: [ babel({
    exclude: 'node_modules/**'
  }) ],
  dest: 'bundle.js'
};

引入 rollup-plugin-babel 并且在 plugins 数组中使用，保证 node_modules 目录下的文件不会被 Babel 处理。

现在，当你运行 Rollup 构建你的包时，所有的 ES6 代码都会被转换成 ES5 代码。

  • 以上步骤适用于 Babel 7。如果你正在使用的是 Babel 6，@babel/core 和 @babel/preset-env 应分别替换为 babel-core 和 babel-preset-env。
