# 小程序知识积累

## 小程序的导出功能 (请求头不能添加 Referer)

- 先调用文件下载， 生成微信临时文件 

```js
wx.downloadFile({})  
// 或 
uni.downloadFile({})
```
  
- 需要注意的是： 这里的请求头，不能添加一些 Referer, eg： token、Date等

- 在调用文件预览功能

```js
wx.openDocument({}) 
// 或 
uni.openDocument({})
```

- 最后在预览界面做下载、转发等

## 小程序调用API

- 获取用户手机 与 用户信息是要收费的

- 调用小程序的API， 需要在用户隐私保护协议里面进行勾选
