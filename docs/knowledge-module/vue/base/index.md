# vue 项目的搭建

## 使用 vite 创建 vue 项目

- 安装 vite

```js
npm install vite -g
```

- 创建项目

```js
npm create vite@latest
```

- 安装依赖

```
cd <projectName>

pnpm install
```

- 安装 vue-router

```
pnpm add vue-router
```

- 安装 pinia

```js
pnpm add pinia
```

## vue 官网创建项目

- 创建项目

```js
npm create vue@latest <projectName>
```
