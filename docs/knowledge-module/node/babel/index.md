# Bable 的基本使用方法

## Babel 的基本概念

- Babel 是一个 JavaScript 编译器，允许开发人员使用最前沿的 JavaScript 编写代码，然后 Babel 将其转换为老式的 JavaScript，让更多的浏览器能够理解

- 具体的可以阅读 [Bebel 官网](https://babel.nodejs.cn/docs/)
