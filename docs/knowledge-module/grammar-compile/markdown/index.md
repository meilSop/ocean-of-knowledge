# markdown 文件的编译语法

## 1. 标题用 # 号来实现

- h1-h6 使用 # —— ######

## 2. 两侧有单 \* 号是斜体

```ts
*斜体的文字*
```

_斜体的文字_

## 3. 两侧有双 \* 号是加粗

```ts
**斜体的文字**
```

**加粗的文字**

## 4. 两侧有三 \* 号是斜体加粗

```ts
***斜体加粗文字***
```

**_斜体加粗文字_**

## 5. 无序列表用 - + \* 任何一种都可以

```ts
- 无序号 1

* 无序号 2

- 无序号 3
```

- 无序号 1

* 无序号 2

- 无序号 3

## 6. 有序号

```ts
1. 有序号1
2. 有序号2
```

1. 有序号 1
2. 有序号 2

## 7. 有序号与无序号混合使用 (上一级和下一级之间敲三个空格即可)

```ts
- 无序号第一层 1
   - 无序号第二层 1
      1. 有序号第三层 1
- 无序号第一层 2
```

- 无序号第一层 1
  - 无序号第二层 1
    1. 有序号第三层 1
- 无序号第一层 2

## 8. 一个箭头的引用， 两个箭头双层引用

```ts
> 单层引用

> > 双层引用
```

> 单层引用

> > 双层引用

## 9. 代码块的使用 ``

```ts
;`引用的代码块`
```

`引用的代码块`

## 10. 代码片段的使用 ` `

````ts
;```
  import Case from './components/case/index.vue'
```
````

```ts
import Case from './components/case/index.vue'
```

## 11. 超链接的使用 []()

```ts
  [跳转到百度](https://www.baidu.com)
```

[跳转到百度](https://www.baidu.com)

```

## 14. 三个或者三个以上的 - 或者 \* 都可以。

```ts
  ---
  分割线1

  ***
  分割线2

  ___
  分割线3
```

---

分割线 1

---

分割线 2

---

分割线 3

## 15. 表格

```js
| 年龄 |  姓名  | 班级 |
| ---- | :----: | ---: |
| 12   | 离宿舍 | 五行 |
```

| 年龄 |  姓名  | 班级 |
| ---- | :----: | ---: |
| 12   | 离宿舍 | 五行 |

## 16. 换行语法

- 只需要在行末输入两个即以上的空格即可再回车即可执行真正的换行；

## 17. 段落语法

- 要创建段落，请使用空白行将行或多行文本进行分隔。即在两个段落之间输入一个空行进行分隔，Markdown 会自动识别为段落。
