# 3个月Java后端速成计划（MD版）

- 目标：零基础 → 能独立写 SpringBoot 接口 → 对接前端 → 上线项目 → 为 AI 全栈打底

全程不搞花活，只学企业真实能用的，适配前端转Java后端人群，兼顾AI全栈前置需求。

## 一、整体节奏

- 第 1 个月：Java 基础 + 数据库 + 环境搭建（打地基，适配前端思维）

- 第 2 个月：SpringBoot 核心开发（能独立写接口，对接前端需求）

- 第 3 个月：登录权限、缓存、项目实战 + 部署（能上线，为AI对接铺垫）

## 二、第 1 个月：Java 基础 + MySQL + 环境（打地基）

### 第 1 周：环境 + Java 基础语法

- day01：JDK8 安装、IDEA 安装、Maven 配置、第一个 HelloWorld（搞定开发环境）

- day02：变量、数据类型、运算符、输入输出（基础语法入门，类比前端变量定义）

- day03：if / else / switch / 三目运算（流程控制，和前端逻辑一致，快速上手）

- day04：for、while、do-while、break、continue（循环语句，练熟简单遍历）

- day05：数组、遍历数组、常见小案例（求和、最值）（基础数据结构，类比前端数组）

- day06：方法定义、参数、返回值、重载（函数封装，和前端函数逻辑相通）

- day07：复习 + 小练习（学生成绩管理控制台程序，巩固本周内容）

### 第 2 周：面向对象（Java 核心）

- day08：类与对象、成员变量、构造方法（面向对象基础，理解类的封装思想）

- day09：封装、private / getter / setter、this（权限控制，类比前端私有属性）

- day10：继承、super、方法重写（代码复用，理解继承的核心场景）

- day11：接口、多态、抽象类（面向对象核心特性，后端接口设计基础）

- day12：常用集合：List、ArrayList、HashMap（后端高频，类比前端数组/对象）

- day13：Lambda、Stream 流（前端一看就懂，简化集合操作，提升开发效率）

- day14：异常处理 try-catch、自定义异常（后端必备，学会捕获和处理报错）

### 第 3 周：MySQL 必学（后端吃饭家伙）

- day15：MySQL 安装、Navicat 使用、库/表创建（搞定数据库环境，学会可视化操作）

- day16：INSERT / DELETE / UPDATE / SELECT（CRUD 基础，后端核心操作）

- day17：where、order by、limit、like、in（条件查询，满足前端列表筛选需求）

- day18：group by、聚合函数（count/sum/avg）（统计查询，常见业务场景）

- day19：多表查询：内连接、左连接（关联查询，后端高频场景，如用户-角色关联）

- day20：索引简单理解、唯一约束、外键（了解即可，后续优化再深入）

- day21：综合练习：设计用户/角色/菜单表（模拟真实业务场景，练熟表设计）

### 第 4 周：Maven + MyBatis（连接数据库）

- day22：Maven 依赖管理、pom.xml（项目依赖配置，类比前端package.json）

- day23：MyBatis 入门、配置、连接 MySQL（Java 操作数据库的核心框架）

- day24：MyBatis 增删改查、参数传递（实现基础CRUD，对接数据库）

- day25：MyBatis-Plus 快速入门（简化 CRUD，减少重复代码，提升效率）

- day26：分页查询、条件构造器 QueryWrapper（满足前端分页、筛选需求）

- day27：小案例：用户列表、新增、删除接口雏形（衔接后端接口开发）

- day28～day30：复习 + 把前面所有内容串一遍，能独立写简单查询（巩固基础，避免遗忘）

## 三、第 2 个月：SpringBoot 核心开发（真正写后端接口）

### 第 5 周：Spring & SpringBoot 入门

- day31：Spring 核心 IOC、AOP（理解概念即可，不用死磕源码，知道作用）

- day32：SpringBoot 项目创建、目录结构（熟悉后端项目规范，类比前端项目结构）

- day33：@Controller / @RestController / @RequestMapping（接口注解，定义接口路径）

- day34：GET、POST 请求、@RequestParam、@PathVariable（接收前端请求参数）

- day35：@RequestBody 接收 JSON、统一返回对象（对接前端JSON请求，规范返回格式）

- day36：跨域配置、静态资源访问（解决前后端联调跨域问题，前端熟悉场景）

- day37：小练习：写 5 个基础接口（用户增删改查，实现简单接口功能）

### 第 6 周：参数校验 + 常用功能

- day38：Validation 参数校验（@NotBlank/@NotNull，减少前端校验压力，规范请求）

- day39：全局异常统一处理（后端必备，统一报错返回格式，方便前端对接）

- day40：日志使用 slf4j + logback（打印接口日志，方便排错，类比前端console）

- day41：文件上传、本地存储（实现前端文件上传对接，常见业务需求）

- day42：接口文档 Knife4j（Swagger）（自动生成接口文档，方便前后端联调）

- day43：多环境配置（dev/prod）（区分开发、生产环境，企业级开发规范）

- day44：综合练习：完整 CURD 模块（整合本周内容，实现一个完整功能模块）

### 第 7 周：Redis 缓存（必会）

- day45：Redis 安装、基础命令 string/hash/list（缓存基础，理解缓存作用）

- day46：SpringBoot 整合 Redis（Java 操作 Redis，实现缓存功能）

- day47：Redis 缓存列表、防止重复查询（减少数据库压力，提升接口性能）

- day48：Redis 过期策略、缓存更新（缓存维护，避免缓存脏数据）

- day49：小案例：首页数据缓存（模拟真实场景，练熟缓存使用）

- day50：复习 Redis 使用场景（总结缓存适用场景，加深理解）

- day51：查漏补缺（弥补本周薄弱点，确保能熟练使用Redis）

### 第 8 周：业务逻辑开发能力

- day52：VO、DTO、PO 概念与使用（规范数据传输，企业级开发必备）

- day53：事务 @Transactional（保证数据一致性，如用户注册+角色分配）

- day54：异步任务 @Async（处理耗时操作，如文件导出、消息通知）

- day55：常用工具类：HuTool（简化开发，减少重复代码）

- day56：接口设计规范、返回码规范（统一接口标准，方便前后端对接）

- day57～day60：独立完成一个模块：用户 + 角色 + 菜单（综合实战，巩固本月内容）

## 五、学完能达到什么水平？

- 能独立负责一个 Java 后端项目，完成接口开发、业务逻辑实现

- 能和前端完美对接（自身前端基础，理解前端需求，联调更高效）

- 能写登录、权限、文件、缓存、接口文档等后端核心功能

- 能独立完成项目部署上线，实现公网访问

- 能直接对接 AI 大模型接口，为 AI 全栈开发打下坚实基础

## 六、配套学习建议（非常重要）

1. 每天保证 2～3 小时 学习时间即可，不用熬夜，注重效率

2. 视频/文档学习不超过 30 分钟，剩下时间全部用来敲代码，实操为王

3. 不要死磕语法细节，优先实现功能，能跑起来、能对接前端即可，后续再优化

4. 遇到报错直接搜索解决（前端转后端，排错能力是优势，善用搜索引擎）

5. 每周留1天复习，避免学了后面忘前面，及时巩固知识点
