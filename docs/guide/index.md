# 组件库简介

## 简介

- 本框架组件库主要是基于 vue3.0 + vite3.0 版本以上 + vue-router + pinia + element-plus + vxe-table + icon-park(字节跳动——图标) + echarts + vue-i18n 等封装的使用于管理平台风格的基础框架， 框架可用简单的配置完成页面的开发以及交互

- 这里对 vue、element-plus 做的是自动导入 + 按需加载;
- 对 echarts、vxe-table 也是做了特殊处理（按需加载）—— 仅仅引入了组件中使用到的模块 【若想支持更多， 需要自己在项目中重新全局导入即可】
