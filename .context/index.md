# ocean-of-knowledge - Project Context

This directory stores persistent context for AI coding assistants.

## Categories

| Category | Description |
|----------|-------------|
| architecture | Architecture decisions and system design |
| decision | Technical decisions and rationale |
| progress | Development progress tracking |
| knowledge | Project knowledge and patterns |
| error | Error history and solutions |
| session | Session summaries |

## Quick Start

Use the MCP tools to save and retrieve context:
- `context_save` - Save context
- `context_auto_load` - Auto-load relevant context
- `context_search` - Search across all context
